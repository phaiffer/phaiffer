## 🧭 How I work

- **Local-first, reproducible.** Every project here runs on a laptop with one `make` command before it touches the cloud.
- **Honest scope.** READMEs say what is implemented and what is still planned. No fake "production" claims.
- **Quality is part of the pipeline.** Data contracts, dbt tests, quarantine tables and CI gates, not an afterthought.
- **End to end.** Lakehouse on one side, Spring Boot + Next.js products on the other, and Terraform in between.
